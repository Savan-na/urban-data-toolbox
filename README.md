# Urban Data Toolbox · 城市数据工具箱

A bilingual (English / 中文) learning site for urban-planning students who are new to Python:
copy-ready code snippets, a worked Brisbane case study (public transport stops, income and rent
by SA2), and a prompt library for asking AI better questions.

- Live site: https://urban-data-toolbox.netlify.app/ and https://savan-na.github.io/urban-data-toolbox/
- Single file: `index.html` (works offline once saved)
